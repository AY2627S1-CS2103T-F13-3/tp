# Developer credits photos

These five PNGs are resized copies of the existing team photographs in
`docs/images/`, as referenced by `docs/AboutUs.md`. Each fits within 252 × 252
pixels while preserving its aspect ratio, providing three times the credits
dialog's 84 × 84 logical display size. The documentation originals are retained.

- ultramanarm.png — Zhu Zhi Yu
- gugrusaurus.png — Vincent Lin
- ben58882.png — Benjamin Ng
- ernestchuaa.png — Ernest Chua
- ys000009.png — Yang Shuo

Bundled for offline display in the developer credits dialog. GitHub profile
buttons open the corresponding public profile only when activated.

Vincent Lin introduced the credits feature and these photographs. Zhu Zhi Yu
optimized the runtime copies with OpenAI Codex assistance using deterministic
Lanczos resizing and lossless PNG compression; no images were generated.
